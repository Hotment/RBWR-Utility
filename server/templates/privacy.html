Privacy Policy

RBWR Utility • Last updated: {{ last_updated or 'November 2026' }}

I am the sole developer of RBWR Utility (including the downloadable RBWR Utility .NET 8 / Avalonia desktop application, the RBWR Utility web platform & public REST API, and the RBWR Utility Discord Bot). This Privacy Policy explains what data is processed when you use these services and how your privacy is protected. By using our services, you also agree to our Terms of Service.

1. Information Collected & Processed

Public Game Server Data

The Operator Tablet, Web Calculator, REST API, and Desktop Overlay fetch in-game data from public RBWR server endpoints (hydrogen.realisticbwr.org/api/public/servers and rbwr.hotment.dev/api/public/servers). This data consists strictly of public plant parameters (such as APRM setpoints, reactor temperature, turbine RPM, and demand timer values) and contains no personal user data or Roblox account identifiers.

Desktop Overlay & Local Roblox Log Reading

To automatically detect when you join or leave an RBWR server, the desktop overlay reads your local Roblox client log files in read-only mode (specifically the tail of recent non-crash *.log files in %LocalAppData%\Roblox\logs or a user-configured directory). It extracts only the public server JobId, PlaceId, and local disconnect markers. The overlay does not read, store, or upload chat logs, Roblox usernames, account IDs, or raw Roblox log contents. The matched Job ID stays on your device to sync with public server data and, if enabled by you, update your local Discord Rich Presence.

Support Tickets, Contact Messages & Discord OAuth2

When you submit a support ticket, bug report, feature suggestion, or private contact message, the server stores your submission details (title, description, category, and any replies) along with an optional contact handle. If you choose to sign in with Discord OAuth2, we receive and store your Discord user ID, username, and avatar to associate you with your tickets or authorized admin sessions. Public tickets and replies may be displayed on the website and synced to configured community Discord channels. If an administrator merges a duplicate ticket into another ticket, your Discord ID and display name may be recorded on the target ticket as a follower so you remain linked to the merged thread. We also process IP addresses and/or anonymized IP hashes for rate limiting, spam prevention, and anti-abuse bans.

Discord Bot

When you interact with the RBWR Utility Discord Bot or invite it to a Discord server, it processes Discord identifiers (user IDs, server/guild IDs, channel IDs, message IDs, and role IDs) as needed to run commands, enforce server-configured moderation, automod, autorole, welcome, FAQ, and role-based command permission settings, dispatch notification DMs, and sync ticket or operational alert threads. When moderation or community features are enabled by server administrators, the bot also stores moderation records (warnings, private moderator notes, temporary ban expiration timers, channel lock states, and a rolling moderation action log), starboard post mappings (message IDs, channel IDs, and reaction counts), and server statistics channel configurations (including public member/channel counts and latest GitHub release version numbers).

Desktop Application Error Reports

If the .NET 8 / Avalonia desktop overlay application encounters an unhandled crash and you explicitly choose to click "Send Report", an anonymous error payload containing the application version, .NET runtime exception traceback, and sanitized local log output is submitted. Reports contain no personal files or private system data and are used exclusively to diagnose and fix software bugs.

REST API Rate Limiting

The public REST API (/api/*) temporarily tracks request timestamps per client IP address in memory to enforce burst and per-minute rate limits. These in-memory counters expire automatically and are not used for profiling.

Browser Local Storage

The web applications use browser localStorage to remember preferences locally on your device (such as your last entered Job ID or selected reactor unit). This data remains on your device and is never transmitted to tracking servers.

2. Cookies, Turnstile Verification & Third-Party Services

I do not use advertising networks, third-party tracking cookies, or web analytics tools (such as Google Analytics). The website uses only essential session cookies when you sign in via Discord OAuth2 or access the admin portal.

Unauthenticated POST actions (such as submitting tickets, sending contact messages, or downloading server archives) are protected by Cloudflare Turnstile to prevent automated spam. Turnstile evaluates verification signals in your browser under Cloudflare's Privacy Policy.

3. Data Security & Disclosure

Submitted tickets, contact messages, bot configurations, moderation/community state files, and crash reports are stored in internal data files on the server. I do not sell, trade, or rent any user data to third parties.

4. Data Deletion & Private Contact

If you have submitted a ticket, contact message, or crash report and would like it removed, or if you have questions regarding privacy, you can send a confidential message directly through the Private Contact Form.
