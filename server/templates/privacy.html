Privacy Policy

RBWR Utilities • Last updated: {{ last_updated or 'August 2026' }}

I am the sole developer of RBWR Utilities (RBWR Thermal Calculator). This Privacy Policy explains what data is collected when you use the RBWR Utilities website, Web Calculator, Operator Tablet, and Desktop Application, how that data is used, and how your privacy is protected.

1. Information Collected & Processed

Public Game Server Telemetry

The Operator Tablet, Web Calculator, and Desktop Overlay fetch in-game telemetry data from public RBWR server endpoints (realisticbwr.org/api/public/servers). This data consists strictly of public plant parameters (such as APRM setpoints, reactor temperature, turbine RPM, and demand timer values) and contains no personal user data or Roblox account identifiers.

Suggestions & Feedback Submissions

When you submit a suggestion or bug report, the system saves your submission details (title, description, category), an optional contact handle/Discord username if provided voluntarily, and an anonymized hash of your IP address. The hashed IP address is used solely for rate limiting to prevent spam and cannot be linked back to your identity.

Desktop Application Error Reports

If the desktop overlay application encounters an unhandled crash and you explicitly choose to click "Send Report", an anonymous error payload containing the application version, python runtime exception traceback, and sanitized log output is submitted. Reports contain no personal files or private system data and are used exclusively to fix software bugs.

Browser Local Storage

The web applications use browser localStorage to remember preferences locally on your device (such as your last entered Job ID or selected reactor unit). This data remains on your device and is never transmitted to tracking servers.

2. Cookies & Third-Party Analytics

I do not use tracking cookies, advertising networks, or third-party web analytics tools (such as Google Analytics). The site and tools are designed purely as functional utilities without user tracking.

3. Data Security & Disclosure

Submitted suggestions and crash reports are stored in secure internal data files on the server. I do not sell, trade, or share any user data with third parties.

4. Data Deletion & Private Contact

If you have submitted a suggestion or report and would like it removed, or if you have questions regarding privacy, you can send a confidential message directly through the Private Contact Form or contact me via the GitHub repository.
